# Financial Report Extraction (FRE)

A structural extraction pipeline for financial reports in **PDF** and **HTML** formats.

## Pipeline

**PDF / HTML → Extraction → RAW JSON → Normalization → NORMALIZED JSON → Table Reconstruction**

## Goal

Preserve the structure and content of financial reports in a machine-readable format as a preprocessing layer for downstream **financial and audit information extraction**.

## Current Status

* PDF and HTML extraction
* RAW JSON generation
* Text normalization
* Initial table reconstruction
* Modular architecture for future semantic processing
